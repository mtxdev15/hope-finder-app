Declare & Believe · Spanish Journey phase

Spanish Journey locale prototypes

Design-only. Not wired to production. Touches no real Journey storage, no Vault, no Worker, no Convex. Nothing here reads or writes a real record. No production identifiers or record values appear anywhere in this document.

The RVR1909 source identifier is now verified. It was confirmed against the live API through the already-deployed Worker, read-only, with no deploy performed: it returns translation: "RVR1909", localized book names, no copyright/FUMS field, and a clean 400 {"error":"Invalid chapter."}. Spanish verses below are the real fetched text, tagged Verificado.

The integration itself is still not built. There is no shared verse-extraction utility and nothing in the Journey fetches Scripture yet. A verified source is not a finished feature, and nothing here should be read as evidence that it is.
Both themes and reduced motion are real, not mocked.

Language-switch · anotaciones

Trigger
declare-lang, already dispatched by the i18n engine. Journey currently subscribes in two places and both re-render the same unchanged content.
After
One listener treats a language change as a content invalidation: drop in-memory content, load …:<newLang>, otherwise show the skeleton and prepare the copy, then re-render whatever surface is open, including an open ritual.
Cache behaviour
Separate versioned records per locale pair mean a switch is a lookup, not a rewrite. Nothing is overwritten in either direction.
Symmetry
es → en restores the untouched original. en → es shows the Spanish copy.
No mixed screen
The transition state replaces content wholesale. There is no frame in which chrome and content disagree.
State preserved
The same Journey, the same day, the same ritual step, completion and pacing all survive the switch untouched.
Atomic swap
The entire content surface is replaced at once. There is no intermediate frame in which chrome and content disagree.
Focus
Focus returns to the corresponding section after loading, so a keyboard or screen-reader user is not dropped back to the top.
Scroll
Scroll context is preserved where practical.
Exact restore
Switching back renders the original English record byte-for-byte, because it was never mutated.

Tone rules. The copy names the technical failure plainly and never implies God is absent or that the person did something wrong. The system never speaks as Jesus: “Estamos preparando” says who is actually doing the work, because the content is AI-assisted and wording it as Jesus preparing the day would misattribute authorship. “Tu camino sigue guardado” answers the real fear at a failure screen, which is losing progress. The Scripture state says why we wait, which turns a limitation into the product’s integrity.
